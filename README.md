# Beauty Obsession

Sito del centro estetico di Boffalora d’Adda. Quattro pagine, con una copertina cinematografica che segue lo scorrimento e una variante leggera per mobile.

Sito pubblico: https://fog-coder.github.io/beauty-obsession/

Il codice è in [`sito/`](sito/README.md). Per avviarlo: `cd sito && npm ci && npm run dev`. La pubblicazione su GitHub Pages avviene automaticamente dopo un push su `main` tramite [GitHub Actions](.github/workflows/pages.yml).

La ricerca grezza, il PDF di processo, gli screenshot di verifica e le reference restano nel workspace locale. Nella repository pubblica sono presenti solo il codice, i documenti di direzione, gli asset originali necessari alla build e le licenze dei font.
